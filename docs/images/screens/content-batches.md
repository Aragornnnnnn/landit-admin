# 콘텐츠 제작·검수 화면 검증

- `content-batches.png`: 최종 기능 스택을 로컬 Next.js 서버에서 실행한 1440px 화면.
- 합성 카페 시나리오와 로컬 API 응답을 사용했다. 운영 DB·사용자 데이터는 포함하지 않는다.
- 기존 관리자 셸과 디자인 토큰을 사용했다. 전용 Figma 시안은 없으며 사용자 요청으로 기존 보고서 화면을 실제 API에 연결했다. 존재하지 않는 Figma 원본 캡처를 만들지 않는다.
- 생성 입력 검증 → 라인업 확인 → 생성 상태 조회 → FIX 검수 → 레벨별 표현 재생성 → OK 검수 → 승인 오류 재시도 → 승인 완료를 브라우저에서 검증했다.
- 390px 모바일 가로 넘침 없음. 전체 611개 테스트·타입·ESLint·Next.js 프로덕션 빌드·운영 의존성 취약점 검사 통과.
- 독립 리뷰에서 상세 조회 경쟁 조건과 검수 근거 누락을 수정하고 재검토했다. DB·스키마·인증·프록시 변경 없음.
- 실제 develop에서 인증된 AI 생성·승인을 실행하거나 배포한 결과는 아니다. 실제 AI 호출 비용이 드는 검증은 수행하지 않았다.
