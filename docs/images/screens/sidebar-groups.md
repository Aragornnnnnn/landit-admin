# 사이드바 그룹 접기

2026-10-25 사용자 요청으로 시나리오 메뉴를 독립 그룹에 모으고 각 그룹의 접기·펼치기를 추가했다. 기존 Figma에 접기 동작은 없으며 화면 명세에 변경을 기록했다.

- `sidebar-groups.png`: 로컬 1440px 화면에서 시나리오·설정 그룹을 펼친 상태.
- 390px 모바일 드로어에서도 접기·펼치기와 메뉴 선택 후 닫힘을 확인.
- 처음 진입하거나 경로가 바뀌면 현재 그룹만 펼침. 같은 경로에서는 여러 그룹을 동시에 열 수 있음.
- API 응답은 합성 자료를 사용했으며 실제 관리자 계정이나 운영 DB를 사용하지 않음.
