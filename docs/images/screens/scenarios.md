# 시나리오 목록 캡처

- `scenarios.png`: 실제 구현 화면을 로컬 1440px 브라우저에서 촬영.
- 검증용 합성 시나리오 25개를 API 경계에서 주입했으며 운영 DB·개인정보를 포함하지 않는다. 화면의 서버 호스트 표시는 설정값이고 실제 인증 조회의 증거가 아니다.
- 검색·페이지 이동·카테고리 필터·상세·새로고침 및 뒤로 가기 복원·503 재시도·미제출 검색어 초기화 확인.
- 390px 모바일에서 가로 넘침과 검색 입력 겹침 없이 표시되며, 선택 시 상세 제목으로 포커스 이동.
- 전용 Figma 원본은 없음. 사용자 요청에 따라 기존 관리자 디자인과 공통 컴포넌트를 사용.
