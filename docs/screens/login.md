# 로그인

Figma — 화면: https://www.figma.com/design/3LwSPCntVV55PU1CIcXbVN/?node-id=1050-7578 · 스펙: https://www.figma.com/design/3LwSPCntVV55PU1CIcXbVN/?node-id=1050-7613
라우트: /login
API: POST /auth/social-login · GET /auth/me (관리자 확인 후보, 미확정)

> 운영자 계정으로 들어오는 문. 사용자 웹과 같은 소셜 로그인을 쓰고, 관리자만 통과시킨다.

| 데스크톱/로그인 – 관리자 아님 | `1050:7594` | 로그인은 성공했지만 관리자 권한이 없는 계정. 버튼 아래에 권한 없음 안내 박스와 "다른 계정으로 로그인" 버튼이 추가된다. |

## 화면 구성

스펙 원문.

- 가운데 카드 — 래디(손 인사) · landit 어드민 워드마크 · "운영자 계정으로 로그인해 주세요" · 카카오 / Google 버튼 · 안내 한 줄
- 이미 로그인돼 있고 관리자면 /로 바로 보낸다

화면 프레임 기준 실제 구성 (데스크톱만 있음, 모바일 프레임 없음).

- 흰 배경 전체 화면 가운데에 "로그인 박스"(너비 420px, 세로 정렬, 요소 간 28px 간격) 하나만 놓인다.
- 박스 내부 순서는 다음과 같다.
  1. 헤더 영역
     - 워드마크 행: `landit` 브랜드 워드마크(84×26) + 텍스트 "어드민"(회색, 18px 굵게)
     - 안내 문구: "관리자 계정으로 로그인해 주세요" (회색, 15px)
  2. 버튼 묶음 (세로, 10px 간격, 박스 전체 너비)
     - `카카오로 로그인` — 노란 배경(#FEE500), 카카오 아이콘(22px) + 텍스트, 둥근 모서리 12px, 좌우 14px·상하 16px 패딩
     - `Google로 로그인` — 흰 배경 + 1px 테두리, 구글 아이콘(20px) + 텍스트, 같은 크기
  3. (관리자 아님 변형에만) 안내 박스 — 연회색 배경(#F2F4F6), 둥근 모서리 10px, 좌우 14px·상하 10px 패딩, 텍스트 12px
     - 예시 카피: "sujin***@gmail.com 계정은 관리자 권한이 없어요. 관리자에게 권한을 요청해 주세요."
  4. 안내 한 줄 (회색, 12px): "랜딧 앱과 같은 계정으로 로그인해요. 관리자 권한이 있는 계정만 들어올 수 있어요."
  5. (관리자 아님 변형에만) `다른 계정으로 로그인` — 배경 없는 텍스트 버튼(회색, 15px), 좌우 14px·상하 16px 패딩

## BE 확인 사항 / 열린 질문

스펙에 별도 그룹은 없고, 데이터 섹션에 적힌 내용과 스펙 텍스트·화면 프레임 사이 차이를 정리한다.

- 관리자 확인 API가 BE에 없다. 임시로 첫 admin 호출의 403 여부로 판별하고, 최종적으로는 social-login 응답의 role 또는 GET /auth/me 중 하나를 BE에 요청해야 한다.
- 스펙 텍스트는 카드에 "래디(손 인사)" 일러스트를 포함하지만, 화면 프레임(1050:7579, 1050:7594)에는 래디 이미지가 없다. 어느 쪽이 맞는지 확인 필요.
- 안내 문구가 스펙 텍스트는 "운영자 계정으로 로그인해 주세요", 화면 프레임은 "관리자 계정으로 로그인해 주세요"로 다르다. 화면 프레임 카피를 우선하되 확인 필요.
- 관리자 아님 안내 박스가 스펙 텍스트는 "빨간 안내 박스"이나 화면 프레임은 연회색 배경(#F2F4F6)·회색 텍스트(#4E5968)다. 화면 프레임 스타일을 우선하되 확인 필요.
- 안내 박스의 이메일은 화면 예시처럼 마스킹(`sujin***@gmail.com`)해서 보여주는지, 원본 이메일을 그대로 보여주는지 스펙에 명시가 없다.
