# 이메일·체험 알림 — LAN-669

라우트: /notifications. 알림 그룹에 추가한다. 기존 카드·입력·확인창·상태 컴포넌트를 재사용한다. 이 화면의 Figma 프레임은 현재 제공되지 않아 기존 어드민 스타일로 구성한다.

- 무료 체험 알림: GET notifications/trial-reminder-settings로 현재 푸시·이메일 설정을 읽는다. 조회 성공 전 저장할 수 없다. 변경 후 대상 채널 ON/OFF 확인창을 거쳐 PUT으로 두 값을 함께 저장한다. 변경 내용이 없으면 저장을 막고, 실패하면 입력을 보존한다.
- OFF는 이후 예약/발송 직전에 적용된다. 이미 접수된 알림은 취소되지 않으며, ON으로 바꿔도 제외된 알림은 재발송하지 않는다.
- 테스트 메일: 수신 주소(공백 제거·이메일 형식·최대 255자)를 입력하고 확인창 후 POST notifications/email-tests {recipient}를 보낸다. 본문은 서버 고정 문구다. 체험 알림 설정과 무관하게 발송된다.
- Idempotency-Key는 같은 수신 주소의 실패 재시도 동안 유지하며 성공 이후 명시적 새 발송에만 새 키를 쓴다. 자동 mutation 재시도는 하지 않는다. 발송 중 중복 클릭과 확인창 닫기를 막는다.
- 접수된 작업 ID를 표시하고 GET notifications/jobs/{id}로 상태를 확인한다. ID 직접 입력 조회도 지원한다. PENDING·PROCESSING만 3초 간격으로 확인하고 오류나 최종 상태에서는 멈춘다. 수동 새로고침 가능.
- ACCEPTED는 제공자 접수로 표시하며 메일함 도착을 의미하지 않는다. UNKNOWN은 재발송 전 확인 필요로 표시한다. 주소는 URL·로그·영구 저장소에 넣지 않는다.
- 로딩·실패/재시도·성공 토스트를 제공한다. 모바일은 카드 한 열이며 NPS는 추가하지 않는다.
