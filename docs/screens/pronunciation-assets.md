# 발음 에셋 — LAN-669

라우트: /pronunciation-assets. 설정 그룹에 추가한다. 별도 Figma 프레임은 현재 제공되지 않아 기존 어드민의 카드·확인창·표 스타일을 재사용한다.

- GET expressions/pronunciation-assets/coverage: 활성 표현 전체 수, 억양별 기준 데이터/음성 보유 수, 각각의 누락 표현 ID를 표시한다. 빈 상태·오류 재시도·수동 새로고침을 제공한다.
- 1단계 기준 데이터 → 2단계 TTS 순서를 안내한다. 각 단계의 S3 매니페스트 키를 입력하고 영향 확인 후 POST import-reference-from-s3 또는 import-tts-from-s3를 호출한다. manifestKey는 URLSearchParams로 인코딩한 쿼리 파라미터다. JSON body가 아니다.
- 기준 데이터 재임포트는 단어 음성 URL을 초기화하므로 확인창에서 TTS 재임포트 필요를 알린다. TTS는 기준 데이터가 먼저 필요하다. 화면 방문 이력으로 단계 실행 여부를 강제하지 않는다.
- 공백 키는 실행할 수 없다. 실행 중에는 두 임포트 모두 잠그고 확인창을 유지한다. 자동 재시도하지 않으며, 오류는 입력과 함께 남긴다.
- 결과는 삽입·갱신 건수와 실패 목록(표현 ID·억양·사유)을 보여준다. 실패가 일부 있어도 성공으로 뭉개지 않는다. 요청이 끝나면 커버리지를 새로 조회한다.
- 모바일에서도 키·실패 사유·누락 ID가 가로로 넘치지 않게 줄바꿈한다.
