## BE 확인 사항 / 열린 질문

스펙 그룹명은 "BE·웹 확인".

- 사용자 웹 대화 화면이 세션 주입 파라미터(?sessionId=)를 받는지, 관리자 계정으로 열려도 되는지

스펙 텍스트와 화면 프레임 사이 차이(참고).

- 화면 프레임 하단 안내는 새 탭 URL을 `landit.im/conversation/scenario/:id`로 적고, 스펙은 세션 주입 파라미터를 `?sessionId=`로 적고 있다. `:id`가 scenarioId인지 sessionId인지, 쿼리로 세션을 넘기는지 확정 필요.
- "진행 중 · 이어서" 배지는 스펙에만 있고 화면 프레임(1050:12764)에는 그려져 있지 않다. 배지 위치·모양은 미정.
- 카드 헤더 "{n}개 · 활성"이 카테고리의 활성 시나리오 개수인지, categoryLocked와 어떤 관계인지 스펙에 명시가 없다(목록 응답에 categoryLocked가 있음).
- 프레임 예시에서 서로 다른 카테고리의 시나리오가 같은 scenarioId(100/101/102)를 쓰는 것은 더미 값이다.
- 모바일 프레임이 없다. 타일 3개 가로 배치가 좁은 폭에서 어떻게 접히는지 미정.

## 구현 메모

- 세션 시작은 클릭 순간에 빈 탭을 먼저 열고, 응답이 오면 주소만 채운다. 응답을 기다렸다 열면 브라우저 팝업 차단에 걸린다. 실패하면 열어 둔 탭을 닫는다.
- 사용자 웹 주소는 `NEXT_PUBLIC_WEB_BASE_URL`로 받는다. 비어 있으면 새 탭을 열지 않고 세션만 만들며, 하단 안내가 그 사실을 말한다.
- 관리자 토큰으로 연 사용자 웹이 이 세션을 이어받는 방법은 아직 미확정이다(스펙의 열린 질문). 지금은 대화 화면 주소만 열어 준다.
- 난이도(`difficulty`)는 BE가 자유 문자열로 준다. 아는 값(BEGINNER·INTERMEDIATE·ADVANCED)만 우리 말로 바꾸고 모르는 값은 그대로 보여 준다.
- "진행 중 · 이어서" 배지는 스펙 텍스트에만 있고 프레임에 없어 만들지 않았다(로컬 상태 기반이라 새로고침에 사라진다).
