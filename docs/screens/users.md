# 사용자

Figma — 화면: https://www.figma.com/design/3LwSPCntVV55PU1CIcXbVN/?node-id=1050-11382 · 스펙: https://www.figma.com/design/3LwSPCntVV55PU1CIcXbVN/?node-id=1050-11802
라우트: /users · /users/[id] (스펙 표기는 /users/[userProfileId])
API: GET admin/users?page&size · GET admin/users/{userProfileId} · GET admin/mailbox/feedbacks?keyword={email}

> 전체 사용자를 가입일 최신순으로 보고, 한 사람의 프로필·학습 요약·보낸 피드백을 본다. 역할 열로 누가 관리자인지도 확인(부여/해제 API 없음). BE에 검색·필터가 없어 임시로 프론트에서 한다 — 진입 시 50명씩 hasNext=false까지 순차 로드한 뒤 로컬 검색·필터·페이징. 진행률을 필터 줄에 보여주고, 다 불러오기 전엔 "불러온 범위에서" 검색됨을 표시. BE 검색이 생기면 서버 검색으로 교체.

## BE 확인 사항 / 열린 질문

스펙 그룹명은 "BE 확인 · 요청".

- 스웨거 버그: AdminUserListResponse.items가 Item 이름 충돌로 피드백 스키마로 표시됨 → 실제 필드 확정 후 컬럼 조정(시안은 이메일·닉네임·상태·레벨·완료 시나리오·푸시·가입일로 가정)
- 나중에: 이메일·닉네임 검색, 정지/해제, 세션·대화 기록

스펙 텍스트와 화면 프레임 사이 차이(참고).

- 스펙 BE 확인 항목은 목록 컬럼을 "이메일·닉네임·상태·레벨·완료 시나리오·푸시·가입일"로 가정한다고 적혀 있으나, 실제 목록 프레임(1050:11383)의 컬럼은 "ID · 이메일 · 닉네임 · 역할 · 상태 · 가입"이다. 목록 API 필드 확정 후 어느 쪽으로 갈지 정해야 한다.
- 라우트 표기가 스펙은 `/users/[userProfileId]`, 이 문서 요청은 `/users/[id]`다. 파라미터 이름만 다르고 값은 userProfileId다.
- 상세 헤더의 역할 칩은 프레임에 "USER"(API 값 그대로)로, 목록 역할 칩은 "사용자/관리자"(한글)로 되어 있다. 통일 여부 확인.
- 학습 요약의 "마지막 학습" 타일이 "오늘"처럼 상대 표기인지(lastLearningDate 기준 FE 변환), 날짜 그대로인지 스펙에 명시가 없다.
- 로드 진행 표시의 총 인원(1,284명)은 목록 API에 총 개수가 없으므로(hasNext만 있음) 어떻게 아는지 불명확하다. 순차 로드가 끝날 때까지는 총 개수를 알 수 없으므로 진행 표시 형식 조정이 필요할 수 있다.

## 구현 메모 (목록 PR)

- BE 목록 응답에 전체 인원이 없다(`hasNext`만 있다). 그래서 프레임의 "650 / 1,284명" 같은 비율을 그릴 수 없어, 진행 표시는 **받은 인원 + 도는 막대**로 대신한다. 다 받으면 "1,284명"만 남는다. BE가 전체 수를 주면 프레임대로 바꾼다.
- 역할 칩의 점은 관리자에만 붙인다(프레임). 목록에서 눈에 띄어야 하는 쪽이 관리자다.
- 검색은 이메일·닉네임 부분 일치(대소문자 무시)다. 아직 다 못 받은 상태에서는 받은 범위에서만 걸린다 — 그 사실을 진행 표시가 계속 말한다.
- 모바일 프레임이 없어 다른 화면과 같은 카드 목록 규칙으로 뒀다.

## 구현 메모 (상세 PR)

- AI 튜터는 번호만 적는다. 프레임의 "#2 (테디)"처럼 이름을 적으려면 튜터 목록 API가 필요하다.
- 역할 칩은 프레임대로 코드 그대로(USER·ADMIN)다. 목록의 "사용자·관리자"와 다른데, 상세는 운영자가 값을 확인하는 자리라 프레임을 따랐다.
- 상단바 제목은 "사용자"까지만이다. 프레임의 "사용자 / #1281 민호"는 상단바가 불러온 사용자 이름을 알아야 해서 아직 붙이지 않았다(편지 편집 화면과 같은 한계).
- 피드백 카드의 행을 누르면 `/feedbacks?open={id}`로 간다 — 답장 화면이 그 주소를 읽는다.
- 프레임 하단의 회색 주석(`GET admin/mailbox/feedbacks?keyword={email} …`)은 스펙 설명이라 화면에 그리지 않는다.
