# 시나리오 목록

LAN-695 후속 요청. 기존 시나리오를 검색하고 상세 정보를 확인하는 조회 전용 화면.
전용 Figma 시안은 없으며, 사용자의 기능 추가 요청에 따라 기존 어드민의 색·폰트·공통 상태를 사용한다.

- 경로: `/scenarios`. develop 메뉴에서만 표시하며 다른 서버에서는 API를 호출하지 않고 안내한다.
- 데이터: 기존 `GET /api/v1/admin/scenarios`. 시나리오 테스트와 같은 조회·캐시 사용. 변경 요청과 세션 생성 없음.
- 범위: 연결된 develop DB의 활성 카테고리·시나리오·언어 버전. 관리자 프로필의 언어와 학습 수준에 따른 시작 대사. 전체 운영 DB나 모든 레벨의 질문 목록이 아님.
- 목록: Day 순 정렬, ID·제목·카테고리·난이도 표시. 서버에서 전체 목록을 받아 클라이언트에서 검색·필터·20개 단위 페이지 처리.
- 검색: 제목·설명·목표·Day·ID. 공백으로 나눈 단어가 모두 포함되면 일치, 대소문자 구분 없음.
- 필터: 카테고리·난이도. 검색 조건 변경 시 첫 페이지로 이동하고 상세 선택 해제.
- URL: `q`, `category`, `difficulty`, `page`(1부터), `scenario`. 새로고침·뒤로 가기로 복원.
- 상세: 설명, 대화 목표, 첫 발화자, 썸네일, 시작 대사와 번역, 사용자 시작 안내, 답변 가이드, 속마음, 캐릭터 ID. 응답에 없는 값은 미등록으로 표시.
- 상태: 로딩, 목록 없음, 검색 결과 없음, 오류·재시도, 선택 항목 없음 구분. 새로고침 실패 시 이전 데이터를 현재 결과로 표시하지 않는다.
- 검증: 검색·정렬·페이지 범위와 잘못된 ID 처리 테스트, 데스크톱 1440px·모바일 390px 브라우저 확인.
